Relaunch brings back the full-screen grid you swipe left and right, with folders, drag to rearrange and instant search. On first launch it restores the layout you already had.

Everything you remember

Your layout, restored

macOS kept Launchpad's database after the upgrade. Relaunch reads it once and puts your pages and folders back exactly as they were. It never changes the original file.

Swipe between pages

Pages follow your fingers, rubber-band at the ends and snap on a flick. A mouse wheel, ⌘← ⌘→ and the page dots work too.

Folders that feel right

Drop one app on another to make a folder, named after the apps' category. Rename it in place, drag apps out, or ungroup it in one click.

Search as you type

Matches the start of any word, initials like “vsc”, and ignores accents. Arrow keys and Return launch without touching the mouse.

Instant

Relaunch stays running in the background, as Launchpad did inside the Dock. It finds 115 apps in about 50 ms and uses no CPU while idle.

No permissions

Open it with the pinch, from the Dock, or from a hot corner. No Accessibility access, no tracking.

Install

Three ways to get Relaunch. Pick whichever you like.

Download

The usual way: open the disk image and drag Relaunch to Applications.

Download Relaunch.dmg

The app isn't notarized by Apple yet, so macOS may warn about it the first time. Here's how to open it.

Terminal

One command downloads the latest release, checks its SHA-256 checksum, installs it and opens it.

curl -fsSL https://relaunch.stack42.tech/install.sh | bash

To remove it later: curl -fsSL https://relaunch.stack42.tech/install.sh | bash -s -- --uninstall. Read the script before running it.

Build it yourself

Only needs Apple's free Command Line Tools. Works on Intel Macs too.

git clone https://github.com/STACK-42/relaunch.git && cd relaunch && scripts/build.sh --install

No Command Line Tools yet? Run xcode-select --install first.

Then pinch with your thumb and three fingers, or drag Relaunch into your Dock. Requires macOS 14 Sonoma or later. The download and Terminal options are for Apple silicon.

Help

If macOS won't open Relaunch

macOS may say “Apple could not verify ‘Relaunch’ is free of malware”. That's because this release isn't notarized by Apple yet, not because anything is wrong with it. The source is public. Any one of these fixes it:

Open Anyway

  1. Try to open Relaunch once, then click Done on the warning.
  2. Open System Settings → Privacy & Security.
  3. Scroll down to Security, where it says Relaunch was blocked, and click Open Anyway.
  4. Confirm with your password or Touch ID, then click Open.

You only need to do this once.

Use the Terminal install instead

Files downloaded by Terminal aren't marked as “from the internet”, so this install doesn't trigger the warning. It still checks the download's checksum.

curl -fsSL https://relaunch.stack42.tech/install.sh | bash

Clear the download flag yourself

If Relaunch is already in Applications, this removes the “downloaded from the internet” mark macOS put on it:

xattr -dr com.apple.quarantine /Applications/Relaunch.app

Only do this for apps you trust.

Bring back the pinch

Pinch with your thumb and three fingers to open Relaunch, and spread them to close it, just like Launchpad. No extra apps or permissions needed.

1. Say yes once

macOS uses the same pinch for its own Apps view, and its Apps switch in Trackpad settings doesn't turn off. The first time you open Relaunch, it offers to turn off macOS's pinch for you.

Apple's Apps view is still one ⌘Space away.

2. Pinch

  1. Pinch in to open Relaunch.
  2. Spread to close it.
  3. Spread while it's closed to show the desktop, as before.

Changed your mind? Right-click the Relaunch background and toggle Pinch Opens Only Relaunch.

No trackpad?

Click Relaunch in your Dock, or use a hot corner:

defaults write com.ahmedalghali.Relaunch hotCorner bottomLeft

Then quit and reopen Relaunch. Also accepts topLeft, topRight and bottomRight.

Update or uninstall

Relaunch runs in the background, so it has no Quit in the Dock or menu bar. Everything is in the menu you get by right-clicking the Relaunch background.

Update

  1. Right-click the Relaunch background and choose Quit Relaunch.
  2. Drag the new Relaunch into Applications and replace the old one.

Your layout and settings stay. Or rerun the Terminal install, which does both:

curl -fsSL https://relaunch.stack42.tech/install.sh | bash

Uninstall

Right-click the Relaunch background and choose Uninstall Relaunch…. It turns macOS's own pinch back on, removes the login item, your layout and settings, and moves the app to the Trash. From Terminal:

curl -fsSL https://relaunch.stack42.tech/install.sh | bash -s -- --uninstall

Installing again later starts fresh and can bring back your Launchpad layout again.

Already deleted it?

Turn macOS's pinch back on in System Settings → Trackpad → More Gestures → Apps, and remove Relaunch from your Dock.

Questions

Can it open with the pinch gesture or the F4 key?

The pinch, yes: see Bring back the pinch. The F4 key stays with macOS's Apps view and can't be remapped without extra tools, so Relaunch also offers the Dock icon and an optional hot corner.

Can I add a keyboard shortcut or change the grid size?

Relaunch has no keyboard shortcut by default. Add one, or change the grid, with defaults, then restart Relaunch:

defaults write com.ahmedalghali.Relaunch hotkey "ctrl+opt+l"
defaults write com.ahmedalghali.Relaunch columns -int 8
defaults write com.ahmedalghali.Relaunch hotCorner bottomLeft
I never used Launchpad. Does it still work?

Yes. Without an old layout it starts with Apple's apps first, utilities in an “Other” folder, and everything else alphabetically.

How do I uninstall it?

Run curl -fsSL https://relaunch.stack42.tech/install.sh | bash -s -- --uninstall, or quit it from the right-click menu on the background, then delete the app and ~/Library/Application Support/Relaunch.

How was it built?

The project's research notes explain how Apple's original worked, based only on inspecting the system. Relaunch's code is original and uses public APIs. Read the notes.
